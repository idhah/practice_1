# Mine Fuel Management System



## Features
- Dashboard with fuel received, issued and estimated tank balance
- Equipment register
- Fuel receipt entry
- Fuel issue/refuelling entry
- Consumption summary by equipment
- SQLite database
- Simple responsive interface

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:
   `pip install -r requirements.txt`
4. Run:
   `python app.py`
5. Open `http://127.0.0.1:5000`

The SQLite database (`fuel.db`) is created automatically on first run.
